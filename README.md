# VividBoost Addon Minecraft Mod

VividBoost Addon is a client-side Fabric Minecraft mod that toggles a brighter visual profile and reduced particle clutter for clearer gameplay.

## Install

1. Install Fabric Loader for Minecraft Java Edition 1.21.1.
2. Install Fabric API for Minecraft 1.21.1.
3. Place the VividBoost Addon mod JAR in your Minecraft `mods` folder.
4. Launch Minecraft using your Fabric profile.

## Use

1. Press `V` in-game to enable or disable the visual profile.
2. When enabled, the mod sets gamma to maximum and particles to Minimal.
3. When disabled, it restores the gamma and particle settings saved when you enabled the profile.
4. Check the action bar for the profile’s current state. To change the key, open Minecraft’s Controls menu and find the Vibrant Visuals category.

Requirements: Minecraft Java Edition 1.21.1, Fabric Loader 0.16.10 or newer, Fabric API, and Java 21.
